# Changelog

## 0.2.0 - 2026-08-23

- Added production Kubernetes manifests, immutable release images, health probes, autoscaling, and migration jobs.
- Added Prometheus metrics and alerts, structured request logs, optional OpenTelemetry tracing, and operations/recovery runbooks.
- Added user-scoped price alerts with threshold evaluation and re-arming.
- Added deterministic SMA crossover backtesting with next-candle execution, transaction fees, benchmark comparison, and drawdown metrics.
- Hardened dependencies and production images; CI and security workflows gate releases.

## 0.1.0 - 2026-08-23

- Published the initial production container baseline for the FastAPI backend and Next.js frontend.
